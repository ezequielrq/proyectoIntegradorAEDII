## 🛠️ Estructura del Proyecto
* **`src/`**: Código fuente modularizado en Lenguaje C.
  * `TAD Paciente`: Definición de registros y gestión de datos personales.
  * `TAD Sala de Espera`: Implementación de Cola dinámica FIFO (First-In, First-Out).
  * `Persistencia`: Lectura y escritura binaria (`.dat`).
  * `Corte de Control`: Generación de informes estadísticos.
* **`docs/`**: Documentación formal, informe del proyecto en PDF y flyer promocional.
